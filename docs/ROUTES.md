# API routes

Generated by `scripts/generate_routes_doc.py` from the live route table. Do not edit by hand; re-run the script (`--check` verifies it is current). Not served by the API.

547 HTTP routes (203 admin). Routes marked *alias* are the unprefixed twins of `/api/...` routes (`core/api_aliases.py`); they run the same handler with the same auth and limits and are hidden from the OpenAPI schema. `/api/admin/*` and `/api/graphics/auth/*` are never aliased. New routes should not use the `/api/` prefix.

Auth column: `public` = no credentials; `admin` = `require_admin` dependency (admin session cookie); `admin (checked in handler)` = the handler calls `require_admin`/`verify_token` itself; `ADMIN PATH, NO CHECK FOUND` = under an admin path but no check was detected (login/logout/OAuth callbacks are expected here, anything else deserves a look); other values name the dependency that gates the route. Limit column: per-client-IP rate limit (`core/rate_limit.py`).
